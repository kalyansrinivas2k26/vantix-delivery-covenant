# Initial FMEA

This is a qualitative starter FMEA. Numeric S/O/D scores are intentionally not invented at Gate 0.

| Failure mode | Effect | Existing design control | Next validation |
|---|---|---|---|
| Material drift not detected | Governance surprise | deterministic drift taxonomy | Gate 3 rule tests |
| Minor changes accumulate | Baseline silently altered | cumulative-change engine | threshold validation |
| Wrong authority accepts risk | Unauthorised exposure | authority matrix | authority fixtures |
| Milestone marked complete without evidence | False progress | milestone evidence gate | negative tests |
| Benefit claimed without baseline | Misstated value | benefit evidence states | baseline-missing tests |
| AI returns unsupported recommendation | Unsafe decision support | schema + evidence + human gate | provider tests |
