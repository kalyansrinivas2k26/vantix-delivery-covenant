# Process Excellence / Six Sigma Challenge Questions

Use these questions to challenge Gate 0 before the design is treated as stable.

1. Are the proposed process units and defect definitions operationally unambiguous enough that two reviewers would classify the same event consistently?
2. Which CTQs are true customer-critical measures versus convenient system measures?
3. What measurement-system failure modes could create false drift, false authority breaches or false benefit conclusions?
4. Is cumulative micro-change best treated as a defect, a leading indicator or a governance trigger—and should those concepts remain separate?
5. What is the correct sampling boundary for each CTQ before any DPMO or capability calculation is attempted?
6. Which metrics are attribute data and which are continuous data, and what analyses would therefore be appropriate or inappropriate?
7. What evidence is required before process stability or capability can be discussed credibly?
8. How should false positives and false negatives in drift detection be measured and controlled?
9. What reaction plan is required when stale or contradictory evidence exceeds its configured threshold?
10. Which controls should be mistake-proofed deterministically rather than monitored statistically?
11. What constitutes an escaped governance defect in this domain?
12. Which CTQs should be monitored for sustainment after a milestone or benefit has initially been accepted?

No external endorsement is implied by this review checklist.
