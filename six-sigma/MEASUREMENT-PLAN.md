# Measurement Plan

Before DPMO, Sigma, Cpk or Ppk:
1. Define process unit.
2. Define each defect operationally.
3. Define opportunities per unit.
4. Define numerator and denominator.
5. Define population and sampling boundary.
6. Assess measurement-system fitness.
7. Confirm process stability assumptions.
8. Version the calculation.

Candidate CTQs are stored in `config/measurement.v0.1.0.json`.
