# Configuration Management Plan — Starter

Controlled configuration items include:
- canonical schemas;
- governance policy configuration;
- measurement configuration;
- prompts and AI response contracts;
- n8n workflow exports once Gate 5 begins;
- deterministic rule implementation;
- fixtures and representative outputs;
- public reports and release evidence.

Changes that alter behaviour require version updates, regression impact review, traceability updates and CI validation. Released artefacts are included in the SHA-256 manifest.

Synthetic and live evidence must never share ambiguous filenames or status labels.
