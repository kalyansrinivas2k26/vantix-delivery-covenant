# Project Charter — Starter

## Purpose
Create an evidence-governed reconciliation layer between Agile delivery execution and authorised project governance.

## Objective
Surface material divergence, authority breaches, unsupported milestone acceptance and unsupported benefit claims early enough for the correct human authority to act.

## Constraints
- Portfolio build uses synthetic data.
- Consequential decisions remain human-owned.
- n8n implementation is gated until the deterministic and canonical designs are accepted.
- No organisation-specific policy is inferred.

## Success criteria
Success is defined by evidence-backed gate completion, not documentation volume.
