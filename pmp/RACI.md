# Initial RACI

R = Responsible, A = Accountable, C = Consulted, I = Informed.

| Activity | Sponsor | PM | Product Owner | Delivery Team | PMO | Risk Owner | Benefit Owner |
|---|---|---|---|---|---|---|---|
| Maintain governance baseline | A | R | C | I | C | I | I |
| Backlog prioritisation | I | C | A/R | C | I | I | C |
| Story estimation | I | I | C | A/R | I | I | I |
| Material scope change | A | R | C | C | C | I | C |
| Risk acceptance | I | R | I | I | C | A | I |
| Milestone evidence pack | I | R | C | R | C | C | C |
| Benefit verification | I | R | C | I | C | I | A |
| Rebaseline | A | R | C | C | C | C | C |

This is a portfolio default, not organisation-specific policy.
