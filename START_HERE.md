# Start Here — VANTIX Delivery Covenant

Use this file as the operating checklist.

## Today’s sequence

1. Create a new GitHub repository named `vantix-delivery-covenant`.
2. Upload the complete contents of this package to the repository root.
3. Commit with: `chore: initialize Delivery Covenant Gate 0 portfolio package`
4. Open the **Actions** tab and confirm the `CI - Delivery Covenant` workflow completes successfully.
5. Open `docs/gates/GATE-0-ACCEPTANCE.md`.
6. Review only the items marked **Owner validation required**.
7. Do not create/import n8n workflows yet.
8. Once Gate 0 is accepted, move to Gate 1 using `docs/gates/BUILD-GATES.md`.

## Do not do yet

- Do not connect customer data.
