# Definition of Ready / Definition of Done — Governance Artefacts

## Ready
A control rule is Ready when:
- requirement ID exists;
- evidence inputs are defined;
- authority boundary is defined;
- deterministic rule is specified;
- expected positive and negative tests are identified.

## Done
A control rule is Done when:
- implementation exists;
- tests pass;
- failure behaviour is demonstrated;
- traceability is updated;
- documentation matches implementation;
- no unsupported release claim is introduced.
