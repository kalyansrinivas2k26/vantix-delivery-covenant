# Documentation Quality Checklist

- [x] Business problem precedes technology.
- [x] One primary decision is explicit.
- [x] Claims distinguish design from implementation.
- [x] Synthetic evidence is labelled.
- [x] Human decision rights are explicit.
- [x] AI prohibited actions are explicit.
- [x] Six Sigma metrics have operational-definition requirements.
- [x] PMP artefacts map to control behaviour.
- [x] Agile authority boundaries are preserved.
- [x] Architecture decisions are recorded.
- [x] Limitations are public.
- [x] Requirements map to controls/contracts/tests.
- [x] Release maturity is evidence-gated.
- [x] Executive one-pager uses thesis/evidence/implication/decision structure.
- [x] n8n implementation is not falsely claimed before Gate 5.
