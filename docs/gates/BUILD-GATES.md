# Build Gates

## Gate 0 — Problem & Evidence Validation
Status: Conditional Pass.

## Gate 1 — Business & Governance Design
Outputs: charter, outcome map, ledgers, authority matrix, drift taxonomy, cumulative-change model, milestone rules, benefit rules, CTQs, risk model, policy definitions.

## Gate 2 — Canonical Data & Schemas
Outputs: data dictionary, synthetic dataset, IDs, schemas, validation and versioning.

## Gate 3 — Deterministic Control Engine
Outputs: executable drift, cumulative-change, authority, milestone, benefit and contradiction rules.

## Gate 4 — Bounded AI
Outputs: prompts, response contracts, confidence controls, critic/challenger, fail-closed validation and human review.

## Gate 5 — n8n Implementation
Outputs: actual importable workflows, integrations, logging, retries, error handling and idempotency.

## Gate 6 — Verification
Outputs: deterministic, integration, failure-mode, provider, clean-import, security and regression evidence.

## Gate 7 — Executive Outputs
Outputs: HTML, JSON, evidence index, trend views, decision outputs, limitations and assurance case.

## Gate 8 — GitHub & Release
Outputs: sanitised public release, CI evidence, checksums, release tier, demo, CV and interview assets.

A gate is not complete because its documents exist. Acceptance requires evidence against its pass criteria.
