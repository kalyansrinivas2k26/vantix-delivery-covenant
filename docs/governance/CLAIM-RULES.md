# Public Claim Rules

Public claims must be traceable to repository evidence.

Forbidden without external evidence:
- production ready
- enterprise proven
- externally certified
- world first
- fully autonomous
- compliant

Permitted evidence-safe language:
- portfolio build
- synthetic demonstration
- evidence-governed design
- deterministic-first controls
- fail-closed routing, when demonstrated by tests
- CI green, only for the exact commit where CI passed
