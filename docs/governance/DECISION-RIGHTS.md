# Initial Decision-Rights Matrix

| Decision | Default authority | System role |
|---|---|---|
| Backlog prioritisation | Product Owner | Validate evidence only |
| Story estimation | Delivery Team | Prohibited from deciding |
| Sprint commitment | Delivery Team | Prohibited from deciding |
| Minor requirement clarification | Product Owner within approved boundary | Check boundary |
| Material scope change | Sponsor / Change Authority | Detect and route |
| Contingency release | Named financial/project authority | Detect and route |
| Risk acceptance | Named Risk Owner | Validate authority |
| Milestone acceptance | Authorised business/project owner | Evidence gate |
| Benefit acceptance | Benefit Owner | Evidence gate |
| Rebaseline | Sponsor / PMO / Governance Board | Detect and route |
| Project closure | Sponsor / Governance Body | Prohibited from deciding |

These are portfolio defaults and must be replaced or explicitly retained as synthetic assumptions before any organisation-specific deployment.
