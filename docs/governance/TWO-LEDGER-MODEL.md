# Two-Ledger Operating Model

## Delivery Reality Ledger
Represents observed Agile execution: project, epic, story, sprint, sprint goal, acceptance criteria, DoR, DoD, status, forecast, carryover, blockers, defects, rework, dependencies, release evidence, linked outcome, evidence ID, source, timestamp and freshness.

## Governance Commitment Ledger
Represents authorised project intent: approved outcome, scope inclusions/exclusions, milestone commitments, acceptance criteria, contingency rules, RAID, decision authorities, benefit baselines/targets/owners, closure criteria, approval evidence, governance version and approval timestamp.

## Reconciliation principle
The Delivery Reality Ledger never overwrites the Governance Commitment Ledger. Differences become explicit findings with evidence references.
