# Drift Taxonomy

| Drift type | Definition | Example |
|---|---|---|
| Scope | Delivery no longer matches authorised scope | Feature added outside baseline |
| Milestone | Forecast/evidence diverges from milestone commitment | Done stories but acceptance missing |
| Benefit | Benefit evidence diverges from target/baseline | Output delivered, outcome unmeasured |
| Risk | Actual exposure differs from accepted position | New risk exceeds appetite |
| Dependency | Dependency state threatens authorised plan | External dependency unresolved |
| Cost / contingency | Consumption crosses configured boundary | Repeated change consumes reserve |
| Acceptance criteria | Criteria change without authorised basis | Definition weakened |
| Authority | Decision made by insufficient authority | PO accepts material scope change |
| Delivery forecast | Forecast diverges from committed milestone | Slip beyond tolerance |
| Governance documentation | Delivery changed but governance record did not | Baseline not updated |

Classifications:
`none`, `isolated_minor_change`, `repeated_minor_change`, `cumulative_material_change`, `unapproved_baseline_change`, `governance_review_required`, `formal_change_request_required`, `insufficient_evidence`.
